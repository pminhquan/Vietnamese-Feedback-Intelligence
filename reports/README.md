# reports/ — experiment outputs

Committed reports live here as hand-reviewed Markdown. Machine-readable
artifacts (JSON) are written to `reports/artifacts/`, which is **gitignored**
because their contents come from local data runs.

When real UIT-VSFC experiments become possible (see
`docs/dataset-uit-vsfc.md`), add one Markdown report per milestone here
containing: dataset fingerprints, exact commands, selected hyperparameters,
metrics, confusion matrix, latency numbers, and an error-analysis section.
Never paste raw student feedback text into these reports.
